Privacy policy: HQ tracker

Last updated: 2 November 2026

HQ tracker is a private dashboard run by Sean Alkemade for his own YouTube channels. This page explains what it reads through Google sign-in and what happens to that data.

What it reads

With the read-only YouTube scope (youtube.readonly) it reads, for the channel you sign in with:

  • the channel's name, handle, subscriber, view and video counts;
  • the channel's videos: title, status (public, scheduled, private), publish time and length;
  • daily view and watch-time totals from YouTube Analytics.

It never uploads, edits or deletes anything, and it does not read comments, messages, email or any other Google data.

Where it goes

The numbers are stored in the owner's private Notion workspace and on the owner's own server, where the dashboard shows them. The sign-in token is kept on that server only to refresh these numbers.

The data is not sold, shared with anyone, or used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can revoke HQ tracker's access at any time at myaccount.google.com/permissions. To have stored data deleted, email the address below.
